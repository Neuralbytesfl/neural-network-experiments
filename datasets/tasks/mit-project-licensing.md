# Task Record: MIT Project Licensing

## Date
2026-09-06

## Task Type
Licensing, ownership attribution, release packaging, documentation.

## Original Request
Add an MIT license to GitHub and make clear that the application and code belong to
the program's creator.

## Problem
The public repository had no detectable root license, explicit copyright-holder
statement, or license bundled with application releases.

## Environment
Public repository: `Neuralbytesfl/neural-network-experiments`. Native arm64 macOS
application and DMG generated by local reusable release scripts.

## Inputs
- The OSI canonical MIT license text.
- GitHub's documented root `LICENSE` detection convention.
- Existing README, CMake configuration, bundle property list, and release scripts.

## Actions Taken
1. Added the canonical MIT license with `Copyright (c) 2026 Neuralbytesfl`.
2. Added prominent Neuralbytesfl ownership and licensing text to the README.
3. Added project description, homepage, and macOS copyright metadata.
4. Embedded `LICENSE.txt` in the application and at the DMG root.
5. Made release verification fail when license attribution is missing.
6. Built and tested the software and both release artifacts.
7. Verified GitHub's detected SPDX license after publishing.

## Files Changed
- `LICENSE`: governing MIT terms and copyright notice.
- `README.md`: visible ownership and license summary.
- `CMakeLists.txt`: project identity metadata.
- `native/NeuroevoStudio/Info.plist`: macOS copyright metadata.
- `scripts/build-macos-app`: embedded app license.
- `scripts/build-dmg`: visible disk-image license.
- `scripts/verify-release`: license verification.
- Specification and this task record.

## Commands Used
See `docs/specs/mit-project-licensing.md`.

## Output
The repository and every generated release identify Neuralbytesfl as the 2026
copyright holder and carry the MIT License.

## Verification
Release builds, tests, bundle verification, disk-image verification, and GitHub
license detection were run before completion.

## Benchmark
Not applicable; no runtime behavior changed.

## Rollback
Revert the licensing commit. Previously received copies retain permissions already
granted under their included MIT license.

## Reusable Pattern
Treat the license as a required release asset and verify its presence alongside the
binary, signature, property list, and icon.
